# Football Scouting & Transfer Intelligence System

An end-to-end data science project focused on football player analysis, market value prediction, and identifying undervalued players using Python and Machine Learning.

## Objectives
- Clean and analyse real-world football data.
- Explore player performance and market valuations.
- Predict player market values.
- Identify potentially undervalued players.
- Build a player scouting and ranking system.

## Tech Stack
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset used
[Transfermarkt Player Score Dataset](https://www.kaggle.com/datasets/davidcariboo/player-scores)
